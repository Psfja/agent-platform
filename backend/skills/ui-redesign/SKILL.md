# 前端设计审计与优化

对现有产品界面（dashboard、数据表格、多步骤产品 UI 同样适用）执行"审计 → 诊断 → 定点修复"，**不重写、不换技术栈、不破坏功能**。

> 规则提炼自 taste-skill 的 redesign 技能（MIT License，https://github.com/Leonxlnx/taste-skill ），
> 并按企业产品界面（数据密集、中文排版）做了适配。

## 执行顺序

1. **Scan**：确定框架与样式体系（Vue/React/vanilla CSS/Tailwind v3-v4），找到全局设计令牌所在文件。
2. **Diagnose**：逐项过下面的审计清单，记录每一项的"命中/未命中"。
3. **Fix**：按文末 Fix Priority 顺序做低风险、高收益的定点修改；每改一类就跑一遍构建与测试。

## 设计审计清单

### 排版
- 全站默认字体（Inter 无处不在）→ 中文产品应优先 `PingFang SC / Microsoft YaHei / system-ui` 栈；西文品牌字体可保留但不得覆盖中文
- 大标题缺少存在感：收紧 letter-spacing（-0.02em 量级）、行高压到 1.2 以内
- 数据密集界面（表格、指标卡、Token/时长数字）→ `font-variant-numeric: tabular-nums`
- 只有 400/700 两个字重 → 引入 500/600 做层级
- 孤立词换行 → 标题加 `text-wrap: balance`，段落 `text-wrap: pretty`

### 配色与表面
- AI 紫/蓝渐变指纹（最典型）→ 保留品牌色可以，但饱和度须 <80%，并收敛为"单一强调色"
- 冷灰与暖灰混用 → 统一一种灰系（本项目为冷灰）
- 纯黑 `#000` 背景/阴影 → 用带色相的黑；阴影统一用与背景同色相的低透明色
- 高饱和强调色四处飞 → 同语义同一色（成功绿/告警琥珀/危险红各一处定义）
- 纯平无层次 → 背景加极 subtle 的 radial 渐变或噪点；卡片阴影带背景色相
- 光照方向不一致 → 全站阴影同一 `rgba(24,31,51,…)` 冷色家族

### 布局与间距
- 全部居中对称 → 标题左对齐、内容不对称排布
- 三列等宽卡片 → 打破为 zig-zag / 不对称网格 / 指标+列表混合
- `100vh` → `100dvh`（移动端浏览器地址栏跳动）
- 无 max-width 容器 → 1200–1440px 约束
- 卡片高度强制相等 → 允许变高或内容区固定起点
- 圆角一律相同 → 内层更小（6–8px）、容器更柔（10–14px）
- 上下 padding 永远相等 → 光学调整：底部略大
- 缺白 → 数据台可密，营销/登录/空状态页要翻倍留白

### 交互与状态
- 按钮无 hover → 补背景位移/微缩放
- 无按压反馈 → `:active { transform: scale(0.98) }`
- 瞬时切换无过渡 → 交互元素统一 200–300ms
- 缺 focus ring → `:focus-visible` 必须可见（无障碍硬要求）
- 只有转圈 loading → 骨架屏（形状贴合布局的 shimmer）
- 空状态裸白 → 设计"引导式空状态"（图标+一句话+行动按钮）
- 错误用 `alert()` → 内联错误文案
- 死链按钮（点不动、`#`）→ 要么接真实行为，要么禁用/提示"即将上线"
- 导航无当前态 → active 样式必须明显
- `prefers-reduced-motion` → 提供降级（禁用动画）

### 组件模式
- 万能卡片（边框+阴影+白底三件套）→ 能省则省：只用底色或只用间距
- 永远"一实心+一幽灵"按钮 → 增加 text 按钮/次级层级降噪
- 药丸式 "New/Beta" 徽章 → 方形或纯文字
- 一切皆弹窗 → 简单操作用行内编辑/抽屉
- 头像只有圆形 → 圆角方形（squircle）更不"模板化"

### 图标与内容
- 图标全来自同一库但笔画宽度不统一 → 统一 stroke-width
- 文案 AI 腔（"赋能/无缝/极致/解锁"）与感叹号成功提示 → 平实、主动语态、不加戏
- 占位假数据（John Doe、99.99%）→ 真实感数据（47.2%、具体姓名）

### 代码质量与战略遗漏
- div 汤 → `nav/main/section/article/aside`
- 行内样式乱飞 → 全部进设计系统
- 任意 z-index（9999）→ 建立 z-index 令牌（30 topbar / 40 sidebar / 60 菜单 / 100 模态）
- 无 favicon → 必须补品牌 favicon
- 缺 meta（og:title/description）→ 补齐
- 无自定义 404 → 有品牌感的兜底页
- 无跳转到内容链接 → 补 skip-link（键盘用户）

## Fix Priority（视觉收益 / 风险排序）

1. 字体与数字排版（tabular-nums、标题收紧）
2. 调色板清理（去冲突色、收敛强调色、统一灰系）
3. hover/active/focus 状态
4. 布局与间距（网格、max-width、留白）
5. 替换模板化组件
6. 补 loading/empty/error 状态
7. 排版细节精修（letter-spacing、text-wrap）

## 规则

- 沿用现有技术栈，不迁移框架与样式库
- 不破坏功能；每次修改后跑测试与构建
- 引入新依赖前先查 package.json
- 改动小而聚焦，可审查
